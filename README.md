# mini-stack-overflow

A responsive question-and-answer web application inspired by Stack Overflow.

## About the Project

Mini Stack Overflow is a frontend web application where users can ask questions, search existing questions, add tags and vote on questions.

The project was created to practice frontend development, JavaScript logic and structured data handling.

## Features

- Ask questions
- Search questions
- Upvote and downvote questions
- Add question tags
- Display question and answer counts
- Responsive design
- LocalStorage data persistence
- User input validation
- Clean and simple interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
